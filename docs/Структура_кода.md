# Как читать исходный код CyberClub

Начинайте с Program.cs, затем переходите к Core.cs и классам работы с данными.

| Файл в src | Назначение |
|---|---|
| Program.cs | Запуск приложения и закрытие общего контекста при выходе. |
| Core.cs | Общий Core.Context, сохранение и выполнение запросов к БД. |
| Account.cs | Данные вошедшего пользователя и его роль. |
| Passwords.cs | Проверка формата пароля, хэширование и сравнение хэшей. |
| AuthService.cs | Вход, регистрация, капча и смена пароля. |
| Field.cs | Описание одного поля редактора. |
| Entity.cs | Описание раздела приложения. |
| Catalog.cs | Восемь разделов, их поля, запросы и списки выбора. |
| ClubService.cs | Проверка данных и прав, добавление, изменение, удаление и выручка. |
| MainWindow.cs | Конструктор окна, навигация, темы и общие элементы интерфейса. |
| MainWindow.Authentication.cs | Формы входа, регистрации и смены пароля. |
| MainWindow.Data.cs | Таблицы, поиск, фильтр, сортировка и редактор записей. |
| MainWindow.Reports.cs | Диаграммы и сохранение отчётов. |
| MainWindow.Dialogs.cs | Обработка ошибок, сообщения и подтверждения. |
| MainWindow.Screenshots.cs | Снимки интерфейса для автоматической проверки. |
| Exporter.cs | Формирование файлов DOCX, XLSX и PDF. |

Файлы MainWindow.*.cs являются частями одного класса MainWindow: ключевое слово partial позволяет разложить его по назначению. Это не отдельные окна. В обозревателе решений эти файлы сгруппированы под MainWindow.cs.

Пример последовательности при сохранении: MainWindow.Data.cs собирает значения полей → ClubService.Parse проверяет их → ClubService.Save изменяет сущность через Core.Context → Core.SaveChanges сохраняет изменения → таблица обновляется.

Сгенерированные классы таблиц находятся в Models/CyberClubModel.cs. Для изменения структуры таблиц сначала обновляется модель EDMX, затем запускается шаблон CyberClubModel.tt.

Единые отступы и переносы строк заданы в .editorconfig. В Visual Studio команда «Правка → Дополнительно → Форматировать документ» использует эти правила.
